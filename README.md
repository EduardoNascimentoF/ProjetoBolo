# ProjetoBolo
Um site voltado para mais administração de pedidos de uma loja de bolo:
- Mostra os pedidos pendentes que ainda precisam ser feitos
- Mostra os pedidos ja feitos porém não entregues
- Tem como passar os pedidos para concluido, entregue e pendende, quantas vezes quiser)
- Quando um pedido for marcado como "Entregue" ele ja faz o calculo do custo fixo(pode ser alterado), receita total e lucro
- mecanicas de crirar conta, banco de dados tanto para usuarios quanto para pedidos(Mysql)
- Sistema de criar conta e logar em conta
- Um projeto para praticar e conhecer mais sobre a biblioteca flask no pythton
